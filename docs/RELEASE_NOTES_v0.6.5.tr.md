# rest-sample-dubbo-consumer 0.6.5

[English](RELEASE_NOTES_v0.6.5.md) | [Türkçe](RELEASE_NOTES_v0.6.5.tr.md)

Bu patch, çalışan consumer uygulamasını platform `4.5.6`, `java-rust-dubbo:0.7.3`,
`rest-sample-utility:0.4.2` ve `rust-sample-model:0.4.2` ile hizalar.

README artık sınırlı ve gömülü Glowroot telemetri yolunu ve isteğe bağlı `0.4.0` bootstrap JAR'ını
açıklar. REST route'ları, Dubbo kontratları, discovery modları, payload'lar ve Java iş kodu değişmedi.
