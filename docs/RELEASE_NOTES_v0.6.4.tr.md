# rest-sample-dubbo-consumer 0.6.4

Bu patch, çalışan consumer uygulamasını `rust-java-rest:4.5.0` platformuna taşır.
`java-rust-dubbo:0.7.2` kullanılmaya devam eder. HTTP katmanı temiz REST ABI `29` ve Glowroot ABI `3`
runtime'ını kullanır.

REST route'ları, Dubbo kontratları, discovery modları, payload'lar ve Java iş kodu değişmedi.
